이 ZIP만 적용하세요. 이전 공유 이미지 ZIP은 적용하지 마세요.
현재 배포된 홈페이지 HTML을 기준으로 head의 메타 정보만 수정했습니다.

1. 압축을 풀어 index.html과 assets 폴더를 찾습니다.
2. GitHub Desktop > Repository > Show in Explorer로 저장소 폴더를 엽니다.
3. index.html과 assets를 저장소 최상위에 복사합니다. 같은 이름은 덮어씁니다.
4. 변경 목록에서 index.html 수정과 새 PNG 이미지 추가를 확인합니다.
5. Commit 후 Push origin을 누릅니다.
