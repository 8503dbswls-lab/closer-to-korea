Closer to Korea - Related Content 3 Cards V1

적용 방법
1. 이 ZIP의 압축을 풉니다.
2. 안의 파일과 폴더를 GitHub Desktop의 closer-to-korea 저장소 최상위 폴더에 복사합니다.
3. 같은 이름 파일이 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
4. GitHub Desktop에서 변경 파일을 확인한 뒤 Commit to main -> Push origin 합니다.

추가 기능
- 공개 Article 및 Product Guide 하단에 관련 콘텐츠를 최대 3개 표시합니다.
- 같은 제품의 Article <-> Product Guide 연결을 최우선으로 표시합니다.
- 그다음 같은 Section, Category, Tag가 겹치는 콘텐츠를 선택합니다.
- 현재 페이지, draft, hidden 콘텐츠는 자동 제외합니다.
- 기존 단일 Related Product / Related Article 영역은 새 카드와 중복되지 않게 숨깁니다.
- PC는 3열, 모바일은 이미지+텍스트형 1열 카드입니다.

대표 이미지 신규 원칙
- Article: 사용 장면, 생활 맥락, 문화적 상황이 보이는 이미지
- Product Guide: 제품 형태, 특징, 모델 식별에 적합한 이미지
- 같은 제품의 두 대표 이미지 경로가 같으면 Admin 검수에서 Warning을 표시합니다.
- Warning은 게시를 막지 않으며 기존 콘텐츠도 순차적으로 교체할 수 있습니다.

향후 게시 자동화
- 새 Article 정적 페이지 생성 스크립트와 새 Product Guide 정적 페이지 생성 스크립트에도
  related-content.css / related-content.js가 자동 포함되도록 반영했습니다.

확인할 페이지 예시
- korean-microwave-steamed-egg-cooker.html
- product-egg-steamer.html
- korean-kimchi-cutter-container.html
- product-kimchi-cutter-container.html
