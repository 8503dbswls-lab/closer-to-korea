Closer to Korea - Mobile Share & Copy Icons V2

이 버전은 문자 아이콘을 사용하지 않습니다.
공유 및 링크 복사 아이콘을 SVG로 CSS 안에 직접 내장하고,
브라우저 캐시를 피하기 위해 related-content.css 주소를 v=2로 변경합니다.

적용 방법
1. ZIP 압축을 풉니다.
2. 폴더 안의 전체 파일과 폴더를 closer-to-korea 저장소 최상위에 복사합니다.
3. 같은 이름 파일은 모두 덮어씁니다.
4. GitHub Desktop에서 Commit 후 Push origin 합니다.

확인 방법
- 배포 후 모바일 페이지를 완전히 닫고 다시 엽니다.
- 첫 번째 원에는 위로 나가는 공유 아이콘이 표시됩니다.
- 두 번째 원에는 겹친 사각형 모양의 복사 아이콘이 표시됩니다.
